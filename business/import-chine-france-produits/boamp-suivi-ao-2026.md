## COMMENT CONFIGURER LES ALERTES BOAMP (GRATUIT)

### Option 1 — Alertes email BOAMP (recommandé)
1. Aller sur **https://www.boamp.fr**
2. Créer un compte acheteur/soumissionnaire gratuit
3. Rubrique "Mes alertes" → "Créer une alerte"
4. Mots-clés à configurer :

**Pour LED éclairage :**
```
luminaires LED éclairage public
fourniture luminaires LED
rénovation éclairage public LED
lampadaires LED solaires
éclairage voirie LED
```

**Pour radars pédagogiques :**
```
radar pédagogique
panneau vitesse
panneau message variable vitesse
signalétique radar école
sécurité routière vitesse
équipement zone 30
```

5. Sélectionner : Type = "Avis de marché" + "Appel d'offres ouvert"
6. Périmètre géographique : France entière (ou par région si préféré)
7. Fréquence : **Quotidienne** (critique au démarrage)

### Option 2 — TED Europa (marchés > seuil européen ~215 000€)
- URL : **https://ted.europa.eu**
- CPV à surveiller :
  - `34993000` — Éclairage routier
  - `31527260` — Lampadaires à LED
  - `34992200` — Panneaux routiers
  - `34996300` — Équipements contrôle trafic

### Option 3 — Agrégateurs gratuits
- **https://www.marches-publics.info** — alertes email gratuites
- **https://www.achat-public.com** — veille gratuite limitée
- **https://www.klekoon.com** — 5 consultations gratuites/jour

## COMMENT RÉPONDRE À UN AO — PROCESSUS ÉTAPE PAR ÉTAPE

### Phase 1 — Analyse (J-10 avant deadline)
- [ ] Télécharger le DCE (Dossier de Consultation des Entreprises) complet
- [ ] Lire le CCTP (Cahier des Clauses Techniques Particulières) — liste les specs exactes
- [ ] Identifier les lots pertinents (souvent Lot 1 = fourniture, Lot 2 = pose)
- [ ] Vérifier si MAPA (< 90 000€ HT) ou Procédure formalisée (> 90 000€ HT)
- [ ] Vérifier les critères de sélection (prix, qualité, délais, garantie, environnemental)

### Phase 2 — Préparation dossier candidature
Documents administratifs obligatoires :
- [ ] **DC1** — Lettre de candidature (formulaire DINUM)
- [ ] **DC2** — Déclaration du candidat (chiffres d'affaires, effectifs)
- [ ] **Kbis** < 3 mois
- [ ] **Attestation fiscale** (impôts) < 6 mois
- [ ] **Attestation URSSAF** < 6 mois
- [ ] Assurance RC Pro (attestation)
- [ ] RIB

### Phase 3 — Offre technique et financière
- [ ] Mémoire technique (présentation société, références, méthode, qualité)
- [ ] **BPU** (Bordereau de Prix Unitaires) — utiliser le template fourni
- [ ] **DQE** (Détail Quantitatif Estimatif)
- [ ] Fiche technique produit + **certificat CE** du fabricant chinois
- [ ] Photos + échantillons si demandés
- [ ] Planning livraison

### Phase 4 — Dépôt
- [ ] Déposer sur **AWS** (Achat Public simplifié) ou plateforme indiquée par l'acheteur
- [ ] Délai : avant la date limite (souvent 17h00 le jour J)
- [ ] Accuser réception email de confirmation

## CALCUL RAPIDE — EST-CE RENTABLE ?

### Seuil de rentabilité par AO

| Paramètre | LED 100W | Radar pédagogique |
|---|---|---|
| Prix achat FOB Chine | ~$90/pc (≈€83) | ~$200/pc (≈€185) |
| Frais port + douane + TVA (récup.) | +€25/pc | +€45/pc |
| **Prix de revient total** | **~€108/pc** | **~€230/pc** |
| Prix vente marché public HT | €220-280/pc | €700-1200/pc |
| **Marge brute unitaire** | **€112-172/pc** | **€470-970/pc** |
| **Marge brute %** | **~104-159%** | **~204-422%** |

**Exemple AO LED 50 unités :**
- CA : 50 × €250 = **12 500€ HT**
- Coût produits : 50 × €108 = 5 400€
- Frais annexes (appel d'offre, livraison France) : ~800€
- **Marge nette estimée : ~6 300€** (50%)

**Exemple AO Radar 10 unités :**
- CA : 10 × €900 = **9 000€ HT**
- Coût produits : 10 × €230 = 2 300€
- **Marge nette estimée : ~5 800€** (64%)
