# Plan d'Action — Import Chine → Marchés Publics France

*À exécuter dans l'ordre. Délai total pour première offre : 3–4 semaines.*

---

## SEMAINE 1 — Lancer le sourcing et la veille AO

### Jour 1–2 : Créer les alertes marchés publics
1. Aller sur **boamp.fr** → créer un compte gratuit
2. Créer alertes e-mail avec mots-clés :
   - "éclairage LED" + "luminaires voirie"
   - "candélabres" + "éclairage public"
   - "radar pédagogique" + "afficheur vitesse"
   - "panneau solaire" + "photovoltaïque"
3. Faire pareil sur **ted.europa.eu** (marchés > 140 000 €)
4. Optionnel : s'abonner à **francemarches.com** (payant, ~50€/mois, très pratique)

### Jour 1–2 : Envoyer les e-mails fournisseurs
➡️ **Voir fichier `emails-fournisseurs.md`** pour les textes complets prêts à copier-coller.

| Fournisseur | Email | Produit |
|---|---|---|
| ZGSM | zgsmled@zgsm-china.com | LED voirie |
| CHZ Lighting | sales10@chz-lighting.com | LED + solaire |
| Novasky Tech | Via made-in-china.com | Radars pédagogiques |
| Nanoradar | Via made-in-china.com | Radars avancés |

### Jour 3–5 : Créer la structure juridique (si pas encore fait)
- **Forme recommandée :** SASU ou EURL (protection patrimoine, TVA déductible)
- **Objet social :** "Commerce de gros de matériel électrique et électronique"
- Code APE visé : 4669B (Commerce de gros d'autres produits intermédiaires)
- Inscription SIRET : via guichet-entreprises.fr (~1 semaine)
- Ouverture compte pro : Qonto, Shine, ou banque traditionnelle

## SEMAINE 2 — Valider les fournisseurs

### Réception des devis
Les fournisseurs chinois répondent généralement sous 24–48h.

**Points à vérifier absolument dans chaque devis :**
- ✅ Prix FOB confirmé par écrit
- ✅ Certificat CE joint (pas juste "CE compliant" — le document officiel)
- ✅ Rapport test LM79/LM80 (pour LED)
- ✅ IP rating (minimum IP65 pour extérieur)
- ✅ Garantie produit (exiger 3 ans minimum, idéal 5 ans)

### Commander les échantillons
- Commander **2–5 unités** chez ZGSM et CHZ (coût ~200–500 €)
- Délai réception : 7–10 jours par DHL/FedEx
- Vérification physique : aspect, certification CE, fiche technique
- Optionnel : envoyer à un labo CE pour validation (LCIE Bureau Veritas, UL)

---

## SEMAINE 3 — Identifier et répondre à un AO pilote

### Sélectionner l'AO cible
Critères de sélection pour un premier AO :
- Budget : 20 000–80 000 € (faisable, pas trop compétitif)
- Type : fourniture de luminaires LED (pas travaux)
- Pas de références exigées (ou "dérogation PME")
- Zone géographique : n'importe quelle commune

### Télécharger et lire le CCTP
Points critiques à vérifier dans le cahier des charges :
- Normes exigées (NF EN 60598, CE, etc.)
- Puissance, flux lumineux, température couleur
- Délai de livraison exigé
- Garantie exigée (souvent 5 ans sur les luminaires)
- Critères de jugement (prix, qualité technique, délai)

### Constituer le dossier de réponse
| Document | Source |
|---|---|
| Mémoire technique | Rédigé par vous avec fiches fournisseur |
| Certificat CE | Fourni par ZGSM/CHZ |
| Fiche produit traduite FR | Fournisseur + traduction |
| Attestations fiscales/sociales | Via impots.gouv.fr |
| Kbis de moins de 3 mois | Via infogreffe.fr |
| Attestation d'assurance RC Pro | Votre assureur |

### Prix à proposer
➡️ **Voir fichier `calcul-marges-detaille.md`** pour les calculs précis.

Règle simple : **Prix vente = Coût rendu France × 2,5 à 3**
- LED 100W : coût 89 € → proposer 220–250 € HT
- Radar péd. : coût 212 € → proposer 750–850 € HT

## SEMAINE 4 — Logistique et première commande

### Mandater un commissionnaire en douane
Contacter pour obtenir un devis :
- **DocShipper** : docshipper.fr (accompagnement complet import Chine)
- **Sino Shipping** : sino-shipping.com
- **Mathez Freight** : mathezfreight.com

Informations à fournir : produit, code HS, port d'embarquement (Shanghai), quantité, poids/volume.

### Conditions de paiement fournisseur
Négocier : **30% acompte à la commande + 70% avant embarquement**
(éviter le paiement 100% à la commande pour les premiers achats)

### Inspection qualité avant embarquement (optionnel mais recommandé)
- **QIMA** (anciennement AsiaInspection) : ~$300 par inspection
- **SGS Chine** : similaire
- Vaut le coup sur commandes > 5 000 €
