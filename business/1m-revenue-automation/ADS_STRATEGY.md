| Phase | Budget total | Répartition |

```

  Objectif: Lead Generation
  Budget: 100€/jour
  
  Ad Set 1: "Travailleurs 35-55 Genève"
    Audience:
      - Âge: 35–55 ans
      - Location: Genève + 20km, Lausanne + 10km
      - Langue: français

```

   □ Oui, 3e pilier 3a

2. "Quel est le montant approximatif ?" (confidentiel)

## Règles d'optimisation automatique (via NotFair MCP)

Configurer ces règles dans les campagnes :

**Google Ads :**
1. Si CPL > 150€ et impressions > 500 → Pause le mot-clé
2. Si CTR < 1.5% et impressions > 200 → Pause l'annonce
3. Si conversion > 3 et CPA < 80€ → Augmenter enchère +20%
4. Plafonner les enchères automatiques à 8€/clic

**Meta Ads :**
1. Si CPL > 60€ après 200€ dépensés → Pause l'ad set
2. Si CTR < 1% après 1,000 impressions → Changer le créatif
3. Si fréquence > 3.5 → Élargir audience ou rafraîchir créatif
4. Budget règle : ne jamais dépenser > 2× le CPA cible en un jour
