## Diagnostic des 3 projets existants

### 1. Leads Pilier Genève — ⭐⭐⭐⭐ PRIORITÉ #1
- **Ticket moyen** : 500–5,000 CHF de commission par client signé
- **Sur 100 leads qualifiés** → 10 clients → 10k–50k CHF
- **Levier 1M€** : commissions sur AUM (1–2% sur 50M CHF = 1M€ — irréaliste en 30j)
- **Réaliste 30j** : 50–150k€ avec aggressive automation + Meta/Google Ads
- **Blocage** : cycle de vente long (rendez-vous, dossier, signature). Automatisable jusqu'au RDV.

### 2. Yacht Location Marketplace — ⭐⭐⭐ PRIORITÉ #2
- **Ticket moyen** : 336€ net par réservation (Modèle A)
- **Pour 1M€** : 2,976 réservations → impossible en 1 mois
- **Réaliste 30j** : 30–100k€ si peak saison estivale (juillet = meilleur mois)
- **Levier** : bundles expérience (Modèle B) → ticket moyen à 560€ net → 1,786 résas
- **Point fort** : juillet est le meilleur mois de l'année pour la location yacht

### 3. Huile d'Olive Tunisie-Chine — ⭐⭐ PRIORITÉ #3
- **Ticket moyen** : B2B, commandes en containers (20t = ~30k€ de marge)
- **Pour 1M€** : ~33 containers signés en 30j → impossible
- **Réaliste 30j** : 1–3 deals = 30k–100k€
- **Cycle de vente** : 2–6 mois. Ne pas miser dessus pour le 30j.

### 4. Toprank Plugin Sales — ⭐⭐⭐ PRIORITÉ #2.5
- **Prix cible** : 99–499€/mois par agence
- **Pour 1M€** : 2,000+ clients en 1 mois → impossible
- **Réaliste 30j** : deal entreprise haute valeur à 10–50k€/an via outbound B2B
- **Levier caché** : vendre du managed service (SEO + Ads géré) à 3–10k€/mois → 10 clients = 30–100k€ MRR

## Stack technique

```
PROSPECTION
  Apollo.io    → recherche de contacts, filtrage, export
  Clay         → enrichissement data, scoring IA, signaux

CRM & SÉQUENCES  
  HubSpot      → pipeline deals, email sequences, scoring leads
  Calendly     → booking auto RDV, sync HubSpot
  DocuSign     → signature contrats automatisée

PAID MEDIA
  Meta Ads     → lead gen B2C pilier + yacht été
  Google Ads   → intent haute (keywords pilier, yacht location)
  NotFair MCP  → gestion campagnes via Toprank (automatisation règles)

AUTOMATION CONNECTEUR
  Make (Integromat) → workflows inter-apps, 0 lead perdu
  Zapier            → fallback + webhooks simples

REPORTING
  Coupler.io   → agrégation données tous canaux → Google Sheets
  Supermetrics → analytics pub consolidé
  Slack        → alertes temps réel deals + KPIs

COMMUNICATION
  Gmail        → follow-ups automatiques
  Slack        → CRM alerts, daily digest revenus
```
