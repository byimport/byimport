# Cross-Platform Content Adaptation

Rules for adapting a single piece of content across multiple platforms.
The goal: consistent brand voice, platform-native format, no copy-paste.

---

## The 5-step adaptation process

1. **Extract the core idea** — one sentence capturing the post's value regardless of platform.
2. **Identify the format** — tip, story, question, announcement, behind-the-scenes, promotion?
3. **Choose the hook per platform** — X wants the punchline first; LinkedIn wants the lesson; Instagram wants the emotion or curiosity.
4. **Trim and expand** — X gets the distilled version (≤ 280 chars); LinkedIn gets the full story with line breaks; Instagram gets the hook + visual context + hashtag block.
5. **Add platform-native elements** — hashtags, CTAs, link placement, emoji density — per `platform-profiles.md`.

## Tone translation matrix

| Core message | Twitter/X | Instagram | Facebook | LinkedIn | TikTok |
|---|---|---|---|---|---|
| Educational tip | "Here's the thing about X 🧵" | "What nobody tells you about X 👇" | "Quick lesson on X:" | "3 years in, I finally understood X." | "POV: you just learned X" |
| Product launch | "We just launched X. It does Y." | "Something we've been building 🤫 → link in bio" | "Big news! We just launched X 🎉" | "Excited to announce X — here's why it matters" | "Wait, we actually did this 👀" |
| Behind-the-scenes | "The real story behind X:" | "A day in our world 📸" | "Here's what really goes on at [Brand]:" | "What building X actually looked like (unfiltered)" | "Day in the life doing X" |
| Opinion / hot take | "Unpopular opinion: X." | "Can we talk about X for a sec? 👀" | "We're going to say it: X. Thoughts?" | "A take that might be controversial: X" | "Tell me you agree — X 🫣" |
| Question / poll | "Hot take: X. Agree? 👇" | "Tell me in the comments: X or Y?" | "We're curious — X or Y? Comment below!" | "Question for [industry]: how do you handle X?" | "Comment X if you've ever dealt with this" |
| Community / milestone | "We hit X. Couldn't have done it without you 🙏" | "We hit X! Thank you 💙 (link in bio for the story)" | "Big milestone: X! Thank you to our community ❤️" | "Proud to share: X. Grateful to everyone who made it possible." | "We hit X and we're crying 😭🎉" |

## Character budget allocation

Adapting a 200-word source piece:

```
Twitter/X:    1 punchy tweet (≤ 240 chars + 1 emoji) OR start a thread (hook tweet + 3–5 replies)
Instagram:    Hook sentence (≤ 125 chars visible) + full story (200–400 words) + line break + hashtag block
Facebook:     Lead hook + 2–3 short paragraphs + 1 question + optional tag CTA
LinkedIn:     Bold opening line + 5–8 short paragraphs (one sentence each) + question + "link in comments"
TikTok:       First 3 words of caption = hook; keep caption under 100 chars; hashtags fill the rest
Pinterest:    Benefit statement (50 chars) + keyword-rich description (200–400 chars) + CTA
Threads:      Conversational fragment (≤ 280 chars, even though limit is 500)
```

## Link placement rules

| Platform | Where to put the link |
|---|---|
| Twitter/X | In the post body |
| Instagram | In bio only; say "link in bio" in caption |
| Facebook | In the post body; remove raw URL after preview card appears |
| LinkedIn | In the **first comment**, not the post body (algo penalty) |
| TikTok | Bio link (≥ 1K followers / business account required) |
| Pinterest | In the pin destination URL field |
| Threads | In the post body (OK) |
| YouTube community | In the post body |

## Emoji density guide

| Platform | Level | Example |
|---|---|---|
| Twitter/X | Low (0–2 per post) | "Big news: we just shipped X 🚀" |
| Instagram | Medium-high (5–15 per caption) | Break up paragraphs; open with one |
| Facebook | Low-medium (1–4 per post) | Use at sentence starts |
| LinkedIn | Low (0–3 per post) | One per bullet in a list is fine |
| TikTok | High (freely used) | Replace punctuation with emoji |
| Pinterest | Low (0–2) | Keep it clean |
| Threads | Medium (2–6) | Casual; mirrors X but slightly warmer |

## Hashtag generation protocol

1. **Seed the search** — extract 2–3 core keywords from the post topic.
2. **Broad tags** (>1M posts on Instagram / >100K on X): 2–3 max. These are reach-oriented but competitive.
3. **Mid-range tags** (100K–1M): 4–6. Best balance of reach and discoverability.
4. **Niche tags** (<100K): 3–5. High-intent audiences; posts stay visible longer.
5. **Always include** at least one branded hashtag if the user has one.
6. **Platform limits:** respect per-platform hashtag counts from `platform-profiles.md`.
7. **Rotate sets** — using the same hashtag set every post signals spam to Instagram. Keep 5–6 different sets and rotate.

---

## Adaptation quality checklist

Before publishing an adapted set, verify:

- [ ] Each variant fits within the platform's character limit
- [ ] Hook is in the first visible text block (first 125 chars for Instagram, first sentence for LinkedIn/Facebook)
- [ ] Hashtag count matches platform rules
- [ ] No external link in Instagram caption or LinkedIn post body
- [ ] At least one CTA per post
- [ ] Tone matches the platform's voice (use tone matrix above)
- [ ] Emoji density is appropriate
- [ ] Brand voice is consistent across all variants
